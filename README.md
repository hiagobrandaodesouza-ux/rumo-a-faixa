# Rumo à Faixa Azul

App de revisão para o exame de faixa azul de jiu-jitsu: quiz de história, ética e regras (IBJJF), técnicas com fotos e vídeos e simulado da prova. Funciona offline e pode ser instalado na tela inicial do celular.

Fotos e vídeos: Wikimedia Commons. Os autores e as licenças estão na tela inicial do app.
